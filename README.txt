LIFEDROP - ONLINE BLOOD DONATION MANAGEMENT SYSTEM
===================================================

HOW TO RUN
1. Extract the ZIP file.
2. Open the online_blood_donation_system folder in Visual Studio Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. No npm install or database setup is required for this demo.

FEATURES INCLUDED
- User registration and login
- Donor / regular user roles
- Donor profile, phone, address, blood group and profile photo
- Medical-condition field
- Last donation date and 90-day interval reminder
- Donor listing, searching and admin edit/delete
- Blood request creation and status tracking
- Blood bank / hospital records
- Basic blood inventory by blood group
- Admin account and role management
- Donation history

IMPORTANT LIMITATIONS
This is a front-end academic prototype. It saves data in the browser's localStorage.
Data does not automatically synchronize between computers or browsers. Passwords and
medical information are NOT securely protected in this demo. Do not enter real patient
or sensitive medical information. For a real deployment, use a backend (such as
Node.js + Express), a database, secure password hashing, server-side authorization,
HTTPS, and proper privacy/security controls.

The 90-day rule is only a simple reminder. It does not establish medical eligibility.
A qualified medical professional and local blood-donation rules must determine eligibility.
